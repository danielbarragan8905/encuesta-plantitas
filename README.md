# 🌙 Encuesta · Noctámbulos

Formulario de encuesta responsivo con un diseño oscuro y personalidad propia, creado para entender los hábitos de las personas que rinden más de noche.

🔗 **Ver el sitio en vivo:** https://danielbarragan8905.github.io/encuesta-plantitas/

## Sobre el proyecto

Este proyecto simula una encuesta express de 3 minutos dirigida a "noctámbulos": personas que trabajan o crean mejor durante la noche. Incluye distintos tipos de campos de formulario (texto, email, número, select, radio buttons, checkboxes y textarea), todos con validación y un diseño 100% responsivo.

## Lo que aprendí / practiqué

- Diseño responsivo con CSS Grid y media queries
- Uso de variables CSS (`:root`) para mantener una paleta de color consistente
- Formularios accesibles con `fieldset` y `legend` para agrupar opciones
- Interactividad con JavaScript vanilla (validación y feedback visual al enviar)
- Tipografía y jerarquía visual para mejorar la lectura

## Tecnologías

- HTML5 semántico
- CSS3 (variables, Grid, media queries)
- JavaScript (vanilla, sin librerías)

## Cómo verlo localmente

1. Clona este repositorio
2. Abre el archivo `index.html` en tu navegador
